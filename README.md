# TagClip（タグ・クリップ）

記事のURLを登録すると、そのページの「タグ」を自動で取得・保存して、タグごとに記事を整理・検索できる個人用ウェブアプリです。
自宅のPCで動かし、同じWi-Fiにつながっているスマホからも使えます。

## 1. できること

| 機能 | 内容 |
|---|---|
| URL登録 | URLを貼り付けて登録。改行区切りで複数まとめて登録できます。対象ドメイン外・登録済みのURLは登録せず、理由を表示します |
| タグの自動取得 | PC側でページを取得し、設定したCSSセレクタに合う要素からタグを取り出します。ページタイトルと登録日時も保存します |
| JavaScript対応 | タグがJavaScriptで後から表示されるサイトでも、設定をオンにすると、見えないブラウザで表示し終えたページからタグを取り出せます |
| 相手サイトへの配慮 | 複数URLは、設定した秒数（初期値3秒）の間隔をあけて1件ずつ順番に取得します |
| エラーの記録 | 取得に失敗したときや、タグが0件だったときは「エラー」として記録し、一覧で確認・再取得できます |
| 一覧・検索 | タグ一覧（件数付き）、複数タグでの絞り込み（AND/OR切り替え）、タイトルのキーワード検索、登録日時での並べ替え |
| メモ・★☆タグ | 登録時にメモと、自分で選ぶ★☆付きのタグを付けられます。★は黄色、☆は青緑で色分けされ、ページから取り直しても消えません |
| 編集 | 記事ごとにタグ・メモを手動で追加・修正・削除。記事の削除 |
| 設定画面 | 対象ドメインとCSSセレクタを画面から変更。URLを1件入れてタグ抽出を試せるテスト機能（保存はしません） |
| バックアップ | 全データをCSVファイルでダウンロード（Excelで開けます） |

## 2. 技術構成と選んだ理由

| 使うもの | 役割 | 選んだ理由 |
|---|---|---|
| **Python** | プログラミング言語 | 初心者向けの解説が非常に多く、Windows・Macどちらでも同じように動きます |
| **Flask** | ウェブアプリの骨組み | Pythonで最も定番の小さなウェブフレームワーク。コードが短く読みやすいです |
| **SQLite** | データベース | 特別なソフトのインストールが不要で、データが **1つのファイル（`tagclip.db`）** にまとまります。数千件程度なら十分高速です |
| **requests** | ページの取得 | Pythonでウェブページを取得する定番のライブラリです |
| **Beautiful Soup** | タグの抽出 | 取得したHTMLから、CSSセレクタで要素を取り出せる定番のライブラリです |
| **Playwright** | JavaScriptの実行（必要なサイトだけ） | 画面を表示しない「見えないブラウザ」を動かす定番のライブラリです。JavaScriptで後から表示されるタグも取り出せます |
| **Waitress** | アプリを動かすサーバー | Windows・Macどちらでも安定して動き、スマホなど他の機器からのアクセスも受け付けられます |

画面はHTMLとCSSで作っており、スマホの狭い画面でも使いやすいレイアウトにしています。

### フォルダの中身

```
self-analysis/
├── app.py               … アプリ本体（画面ごとの処理）
├── database.py          … データベースの読み書き
├── scraper.py           … ページの取得とタグの抽出
├── worker.py            … 登録したURLを裏側で順番に取得する仕組み
├── templates/           … 画面のHTML
├── static/              … 見た目（CSS）と小さなJavaScript
├── requirements.txt     … 必要なライブラリの一覧
├── start_windows.bat    … Windows用 起動ファイル（ダブルクリックで起動）
├── start_mac.command    … Mac用 起動ファイル（ダブルクリックで起動）
└── tagclip.db           … データ（初回起動時に自動で作られます）
```

## 3. インストール（初回だけ）

ご自分のPCに合わせて、**Windows** か **Mac** のどちらかの手順を行ってください。

### 3-1. Python をインストールする

#### Windows の場合

1. ブラウザで <https://www.python.org/downloads/> を開きます。
2. 黄色い「**Download Python 3.x.x**」ボタンを押して、インストーラーをダウンロードします。
3. ダウンロードしたファイルを実行します。
   - 最初の画面の下にある **「Add python.exe to PATH」にチェックを入れる** のが重要です（表示されない新しい形式のインストーラーの場合は、画面の案内どおりに進めてください）。
   - 「Install Now」を押します。
4. インストールできたか確認します。
   - スタートメニューで「**PowerShell**」と検索して開きます。
   - 次のどちらかを入力して Enter を押し、`Python 3.12.x` のようにバージョンが表示されればOKです。
     ```
     py --version
     ```
     ```
     python --version
     ```

> Python 3.10 以上であれば動きます。

#### Mac の場合

1. ブラウザで <https://www.python.org/downloads/> を開きます。
2. 「**Download Python 3.x.x**」ボタンを押して、macOS用のインストーラー（`.pkg`）をダウンロードします。
3. ダウンロードしたファイルを開き、案内に従ってインストールします。
4. インストールできたか確認します。
   - 「アプリケーション」→「ユーティリティ」→「**ターミナル**」を開きます（Spotlight で「ターミナル」と検索しても開けます）。
   - 次を入力して Enter を押し、`Python 3.12.x` のように表示されればOKです。
     ```
     python3 --version
     ```

### 3-2. アプリのファイルをダウンロードする

1. GitHub でこのリポジトリ（`nao1497/self-analysis`）のページを開きます。
2. 画面左上のブランチ名が書かれたボタンを押し、アプリが入っているブランチ（`claude/exciting-hypatia-j2dxnb`、または取り込み後なら `main`）を選びます。
3. 緑色の「**Code**」ボタン →「**Download ZIP**」を押します。
4. ダウンロードしたZIPファイルを展開（解凍）し、中のフォルダをわかりやすい場所に置きます。
   - 例：Windows なら `ドキュメント\tagclip`、Mac なら `書類/tagclip`
   - フォルダ名は何でも構いません。以下、このフォルダを「**アプリのフォルダ**」と呼びます。

> Git を使える場合は `git clone` でも構いません。

必要なライブラリ（Flaskなど）と、JavaScript実行用のブラウザ部品は、次の「起動」のときに自動でインストールされます（初回のみ数分かかります。ダウンロード量は数百MBです。インターネット接続が必要です）。

## 4. 起動と停止

### Windows

**起動**

1. アプリのフォルダを開き、**`start_windows.bat` をダブルクリック**します。
   - 「WindowsによってPCが保護されました」と表示された場合は、「詳細情報」→「実行」を押します（インターネットからダウンロードしたファイルに出る確認です）。
2. 黒い画面（コマンドプロンプト）が開き、初回は準備が行われます（`[1/3]`〜`[3/3]` の表示。数分かかります）。
3. 次のような表示が出たら起動完了です。ブラウザも自動で開きます。
   ```
   ============================================================
    TagClip を起動しました
     このPCから     : http://localhost:8000
     スマホなどから : http://192.168.1.23:8000
     停止するには、この画面で Ctrl + C を押してください
   ============================================================
   ```
4. 初回起動時に「**Windows セキュリティの重要な警告**」が出たら、「**プライベート ネットワーク**」にチェックを入れて「**アクセスを許可する**」を押します（スマホから使うために必要です。詳しくは[7章](#7-スマホからアクセスする)）。

**停止**

- 黒い画面をクリックしてから **`Ctrl` + `C`** を押します。「バッチ ジョブを終了しますか (Y/N)?」と出たら `Y` → Enter。
- または、黒い画面の右上の「×」で閉じても停止します。

> 黒い画面を閉じるとアプリも止まります。使っている間は開いたままにしておいてください（最小化はOKです）。

### Mac

**起動**

1. アプリのフォルダを開き、**`start_mac.command` をダブルクリック**します。
   - 「開発元が未確認のため開けません」と出た場合は、ファイルを **右クリック（または control + クリック）→「開く」→「開く」** を選びます。
   - それでも開けない場合は、ターミナルを開いて `bash ` （bashの後ろに半角スペース）と入力し、`start_mac.command` をターミナルのウィンドウにドラッグ＆ドロップしてから Enter を押します。
2. ターミナルが開き、初回は準備が行われます（`[1/3]`〜`[3/3]` の表示。数分かかります）。
3. 「TagClip を起動しました」と表示されたら起動完了です。ブラウザも自動で開きます。
4. 「"Python"へのネットワーク受信接続を許可しますか？」と出たら「**許可**」を押します。

**停止**

- ターミナルのウィンドウをクリックしてから **`control` + `C`** を押します（`command` ではなく `control` です）。
- その後、ターミナルのウィンドウを閉じてください。

### 手動で起動する方法（うまくいかないとき・仕組みを知りたいとき）

起動ファイルがやっていることを、自分で順に入力する方法です。

**Windows（PowerShell）**
```powershell
cd "C:\Users\あなたのユーザー名\Documents\tagclip"   # アプリのフォルダへ移動
py -m venv .venv                                     # 仮想環境を作る（初回のみ）
.venv\Scripts\python.exe -m pip install -r requirements.txt   # ライブラリを入れる（初回のみ）
.venv\Scripts\python.exe -m playwright install chromium       # ブラウザ部品を入れる（初回のみ）
.venv\Scripts\python.exe app.py                      # 起動
```

**Mac（ターミナル）**
```bash
cd ~/Documents/tagclip                               # アプリのフォルダへ移動
python3 -m venv .venv                                # 仮想環境を作る（初回のみ）
.venv/bin/python -m pip install -r requirements.txt  # ライブラリを入れる（初回のみ）
.venv/bin/python -m playwright install chromium      # ブラウザ部品を入れる（初回のみ）
.venv/bin/python app.py                              # 起動
```

> **仮想環境（`.venv`）とは？** このアプリ専用のライブラリ置き場です。PC全体の設定を汚さずに済み、不要になったらフォルダごと削除すれば元通りです。
>
> `cd` の後ろのパスは、フォルダをPowerShell／ターミナルのウィンドウにドラッグ＆ドロップすると自動で入力できます。

## 5. 最初の設定

起動したら、ブラウザで <http://localhost:8000> を開き、上のメニューの「**設定**」を押します。

1. **対象ドメイン**：記事を登録したいサイトのドメインを入力します。
   - 例：記事のURLが `https://www.example.com/articles/123` なら `example.com`
   - `example.com` と書くと `www.example.com` などのサブドメインも対象になります。
   - URLをそのまま貼り付けても、ドメイン部分だけが自動で取り出されます。
2. **タグ要素のCSSセレクタ**：タグの部分を指定する「CSSセレクタ」を入力します（調べ方は[8章](#8-タグのcssセレクタの調べ方)）。
3. **取得の間隔（秒）**：まとめて登録したときに、1件ごとに待つ秒数です。初期値の3秒のままで構いません。
4. **JavaScriptを実行して取得する**：最初はオフのままにします。テストでタグが取れず、JavaScriptで表示されるサイトだと分かったときだけオンにします（[9章](#9-javascriptでタグが表示されるサイトについて)）。
5. 「**設定を保存**」を押します。
6. 下の「**タグ抽出のテスト**」に記事のURLを1件入れて「テストする」を押し、タグが正しく表示されるか確認します。
   - テストでは、セレクタ欄を書き換えたり「JavaScriptを実行して試す」を切り替えたりして、何度でも試せます（保存はされません）。
   - うまく取れる組み合わせが見つかったら、上の設定欄に同じ内容を入れて保存してください。

## 6. 使い方

### URLを登録する

1. メニューの「**登録**」を開きます。
2. URLを貼り付けます。複数ある場合は **1行に1つ** ずつ貼り付けます。
3. 必要なら **メモ** と **自分で付けるタグ** を入れます（どちらも任意）。
   - これまでに使った★☆タグは、タップして選べます（青くなったら選択中）。
   - 新しいタグは「★を付けて新しく追加」「☆を付けて新しく追加」の欄に入力します。`お気に入り、あとで読む` のようにカンマか「、」で区切ると複数付けられます。先頭の★☆は自動で付きます。
   - メモと自分で付けるタグは、そのとき一緒に登録したすべてのURLに付きます。
4. 「**登録する**」を押すと、1件ずつ結果が表示されます。
   - ✔ 登録しました（タグ取得待ち）
   - ✕ 対象ドメイン外のため登録しません
   - ✕ 登録済みのURLです
   - ✕ 入力の中で同じURLが重複しています
   - ✕ URLの形式ではありません
5. タグは裏側で1件ずつ順番に取得されます。画面上部に「⏳ タグを取得中… 残り N 件」と表示され、終わると「再読み込み」リンクが出ます。
   - 取得中にアプリを停止しても、次回起動時に続きから取得します。

> **★☆タグについて**：先頭が ★ か ☆ のタグは「自分で付けるタグ」として扱います。★は黄色、☆は青緑で表示され、一覧やタグ一覧では先頭に並びます。ページから再取得しても消えません（入れ替わるのはページから取ったタグだけです）。★と☆の使い分けは自由です（例：★＝お気に入り系、☆＝あとで確認系）。
>
> URLの末尾の `#...`（ページ内リンク）は取り除いて保存します。それ以外（`?` 以降など）が違うURLは別の記事として扱います。

### 一覧・検索

メニューの「**一覧**」で記事を見られます。

- **タイトル・メモ検索**：検索欄にキーワードを入れて「検索」。タイトルとメモの両方から探します。スペースで区切ると「すべての語を含む」検索になります。
- **並び順**：「登録が新しい順／古い順」を選べます。
- **状態**：「エラー」を選ぶと、取得に失敗した記事・タグが0件だった記事だけを表示します。エラーの理由も表示されます。
- **タグで絞り込む**：タグをタップして選び（青くなります）、「この条件で絞り込む」を押します。
  - **すべて含む（AND）**：選んだタグを全部持っている記事
  - **どれかを含む（OR）**：選んだタグのどれか1つでも持っている記事
  - タグが多いときは「タグ名で候補を絞る」欄に文字を入れると候補が絞られます。
- 記事の下のタグをタップすると、そのタグの記事一覧に移動します。
- 記事のタイトルをタップすると、元の記事が新しいタブで開きます。

メニューの「**タグ**」では、すべてのタグを件数付きで確認できます（件数順／名前順）。

### 編集・削除・再取得

一覧の各記事の「**編集**」を押します。

- **メモ**：書き換えて「保存する」を押します。
- **タグ**：1行に1つずつ書かれています。行を追加すると追加、書き換えると修正、行を消すと削除です。先頭に ★ か ☆ を付けると「自分で付けるタグ」になります。最後に「保存する」を押します。
- **ページから再取得**：ページからタグを取り直します。ページから取ったタグは置き換わりますが、★☆のタグとメモは残ります。
- **記事を削除**：記事を削除します（元に戻せません）。
- エラーの記事にタグを手入力して保存すると、「取得済み」になります。
- 一覧の「**エラーを再取得**」ボタンで、エラーの記事をまとめて取得し直せます（セレクタを直した後などに便利です）。

## 7. スマホからアクセスする

PCでアプリを起動したまま、**PCと同じWi-Fiにつないだスマホ** のブラウザ（Safari、Chromeなど）で、次のアドレスを開きます。

```
http://（PCのIPアドレス）:8000
```

例：`http://192.168.1.23:8000`

> `https://` ではなく **`http://`** です。最後の `:8000` も忘れずに入力してください。
> 開けたら、ブックマークや「ホーム画面に追加」をしておくと便利です。

### 7-1. PCのIPアドレスの調べ方

いちばん簡単なのは、**アプリ起動時の画面に表示される「スマホなどから : http://...」** を見ることです。

自分で調べる場合：

- **Windows**
  - PowerShell を開いて `ipconfig` と入力 → Enter。
  - 「**Wireless LAN adapter Wi-Fi**」の下にある「**IPv4 アドレス**」（例：`192.168.1.23`）がPCのIPアドレスです。
  - または「設定」→「ネットワークとインターネット」→「Wi-Fi」→ 接続中のネットワーク名（プロパティ）→「IPv4 アドレス」。
- **Mac**
  - 「システム設定」→「Wi-Fi」→ 接続中のネットワークの「**詳細...**」→「**TCP/IP**」→「IPアドレス」。
  - またはターミナルで `ipconfig getifaddr en0` と入力 → Enter。

### 7-2. IPアドレスを固定する

IPアドレスは、PCやルーターの再起動で変わることがあります。変わるとスマホのブックマークが使えなくなるので、固定しておくと便利です。
方法は2つあります。**わかる方を1つ** 行ってください。

#### 方法A：ルーターで固定する（おすすめ）

ルーターの管理画面にある「**DHCP固定割り当て**」「**IPアドレス予約**」「**固定IP割当**」などの機能で、PCに毎回同じIPアドレスを割り当てます。
PC側の設定が不要で、確実です。操作はルーターのメーカー（バッファロー、NEC Aterm、TP-Link など）によって違うので、「ルーターの機種名 DHCP 固定」で検索するか、ルーターの説明書を見てください。PCの「MACアドレス（物理アドレス）」が必要になります（Windows は `ipconfig /all`、Mac は Wi-Fiの「詳細...」→「ハードウェア」で確認できます）。

#### 方法B：PC側で固定する

**Mac（かんたん）**

1. 「システム設定」→「Wi-Fi」→ 接続中のネットワークの「**詳細...**」→「**TCP/IP**」を開きます。
2. 「IPv4の構成」を「**DHCPサーバを使用（アドレスは手入力）**」に変えます。
3. 「IPアドレス」に、今のIPアドレスと **最初の3つの数字が同じ** で、最後の数字だけを大きめ（例：`200`）にしたものを入力します。
   - 例：今が `192.168.1.23` なら `192.168.1.200`
4. 「OK」を押します。

**Windows 11**

1. まず PowerShell で `ipconfig` を実行し、「IPv4 アドレス」「サブネット マスク」「デフォルト ゲートウェイ」をメモします。
2. 「設定」→「ネットワークとインターネット」→「Wi-Fi」→ 接続中のネットワーク名（プロパティ）を開きます。
3. 「IP 割り当て」の「**編集**」を押し、「**手動**」を選んで「IPv4」をオンにします。
4. 次のように入力して「保存」します。
   - IP アドレス：今のアドレスの最後の数字だけを大きめにしたもの（例：`192.168.1.200`）
   - サブネット マスク：メモした値（多くは `255.255.255.0`）
   - ゲートウェイ：メモした「デフォルト ゲートウェイ」（例：`192.168.1.1`）
   - 優先 DNS：ゲートウェイと同じ値
5. インターネットが見られなくなった場合は、「IP 割り当て」を「自動（DHCP）」に戻せば元通りになります。

> 最後の数字を大きめ（200前後）にするのは、ルーターが他の機器に自動で配る番号と重ならないようにするためです。

### 7-3. ファイアウォールの許可設定

スマホから開けないときは、PCのファイアウォール（外部からの接続を防ぐ機能）が接続を止めている可能性があります。

#### Windows

1. **ネットワークを「プライベート」にする**
   「設定」→「ネットワークとインターネット」→「Wi-Fi」→ 接続中のネットワーク名（プロパティ）→「ネットワーク プロファイルの種類」を「**プライベート ネットワーク**」にします（自宅のWi-Fiならこれで問題ありません）。
2. **初回起動時の警告で許可する**
   「Windows セキュリティの重要な警告」で「プライベート ネットワーク」にチェックを入れて「アクセスを許可する」を押します。
3. **警告を閉じてしまった場合**は、スタートメニューで「PowerShell」を **右クリック →「管理者として実行」** し、次の1行を貼り付けて Enter を押します（ポート8000への接続を、プライベートネットワークからだけ許可する設定です）。
   ```powershell
   New-NetFirewallRule -DisplayName "TagClip (port 8000)" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private
   ```
   - 画面で設定したい場合：コントロールパネル →「Windows Defender ファイアウォール」→「詳細設定」→「受信の規則」→「新しい規則」→「ポート」→「TCP」「特定のローカル ポート：8000」→「接続を許可する」→「プライベート」のみチェック → 名前「TagClip」で完了。
   - 不要になったら、同じく管理者のPowerShellで `Remove-NetFirewallRule -DisplayName "TagClip (port 8000)"` で削除できます。

#### Mac

1. 「システム設定」→「ネットワーク」→「**ファイアウォール**」を開きます。
   - **オフ** なら設定は不要です（Macの初期状態はオフです）。
2. オンの場合は、アプリ起動時に出る「"Python"へのネットワーク受信接続を許可しますか？」で「**許可**」を押します。
3. 許可し忘れた場合は、「ファイアウォール」→「オプション...」を開き、一覧の Python を「**外部からの接続を許可**」にします（一覧にない場合は「+」から追加）。

### 7-4. それでもスマホから開けないとき

- スマホが **モバイルデータ通信（4G/5G）ではなく、PCと同じWi-Fi** につながっているか確認してください。
- **ゲスト用Wi-Fi** や、ルーターの「**プライバシーセパレーター**」「ネットワーク分離」機能がオンだと、機器同士が通信できません。
- PCが **スリープ** するとアプリも応答しなくなります。使う間はスリープしない設定にしてください。
- アドレスが `http://`、IPアドレス、`:8000` まで正しいか確認してください。
- まず **PC自身のブラウザ** で `http://（PCのIPアドレス）:8000` を開けるか試すと、原因を切り分けやすくなります（PCで開けてスマホで開けない → ファイアウォールかWi-Fiの問題）。

## 8. タグのCSSセレクタの調べ方

**CSSセレクタ** は、「ページの中のどの部分か」を指定するための書き方です。ブラウザの **開発者ツール** を使うと調べられます。PC（Chrome か Edge がおすすめ）で行ってください。

### 8-1. 開発者ツールでタグ部分のHTMLを見る

1. 対象サイトの記事ページを、PCのChrome（またはEdge）で開きます。
2. ページ上の **タグの文字の上で右クリック** →「**検証**」（Edgeは「**開発者ツールで調査する**」）を選びます。
   - Macの Safari を使う場合は、先に「Safari」→「設定」→「詳細」→「Web開発者用の機能を表示」をオンにし、右クリック →「要素の詳細を表示」を選びます。
3. 画面の横か下に開発者ツールが開き、「**Elements（要素）**」タブで、そのタグ部分のHTMLが色付きで選ばれた状態になります。

たとえば、次のようなHTMLが見えたとします。

```html
<div class="post-tags">
  <a href="/tags/python" class="tag-link">Python</a>
  <a href="/tags/web" class="tag-link">Web開発</a>
</div>
```

### 8-2. セレクタを考える

よく使う書き方は次のとおりです。

| 書き方 | 意味 | 例 |
|---|---|---|
| `.名前` | class="名前" を持つ要素 | `.tag-link` |
| `#名前` | id="名前" の要素 | `#tags` |
| `A B`（スペース区切り） | Aの中にあるB | `.post-tags a` |
| `要素名.名前` | 特定の要素でclassを持つもの | `a.tag-link` |
| `[属性*="値"]` | 属性に値を含む要素 | `a[href*="/tags/"]` |

上の例では、次のどれでもタグ（Python、Web開発）を取り出せます。

- `.post-tags a` … 「post-tags の中のリンク」（おすすめ：範囲がはっきりしている）
- `a.tag-link`
- `.post-tags .tag-link`

**選び方のコツ**

- タグ全体を囲んでいる要素（上の例の `div class="post-tags"`）を見つけ、「その中の a」のように書くと失敗しにくいです。
- `css-1a2b3c` のような **意味のない英数字のclass名** は、サイトの更新で変わることがあるので避けましょう。その場合は `a[href*="/tags/"]`（リンク先に /tags/ を含む）のような書き方が便利です。
- 右クリック →「Copy」→「Copy selector」でもセレクタを取れますが、`... > li:nth-child(2) > a` のような **その1個だけ** を指す細かすぎるものになりがちです。上の表を参考に、短く書き直してください。
- 文字の前の `#` はアプリが自動で取り除くので気にしなくて大丈夫です。

### 8-3. 正しく選べているか確かめる

1. 開発者ツールの「Elements」タブを選んだ状態で **`Ctrl` + `F`**（Macは **`command` + `F`**）を押すと、下に検索欄が出ます。
2. 考えたセレクタ（例：`.post-tags a`）を入力すると、一致した要素が黄色く光り、「1 of 2」のように **件数** が表示されます。
3. 件数がタグの数と同じならOKです。多すぎる場合は、サイドバーの「人気のタグ」など別の場所まで含まれていないか確認し、囲んでいる要素を指定して範囲を狭めてください。
4. 最後に、アプリの **設定画面の「タグ抽出のテスト」** で確認します。ここで取れれば、登録しても同じように取れます。

### 8-4. meta 要素にタグが入っているサイト

ページのHTMLの `<head>` 部分に、次のようにタグが書かれていることもあります。

```html
<meta name="keywords" content="Python, Web開発, 入門">
<meta property="article:tag" content="Python">
```

この場合は `meta[name="keywords"]` や `meta[property="article:tag"]` をセレクタに指定すると、`content` の値をタグとして取り出します（カンマ区切りは自動で分けます）。
画面上のタグが取れないサイトでも、こちらで取れることがあります（次の章も参照）。

## 9. JavaScriptでタグが表示されるサイトについて

### 普通の方法で取れない理由

ブラウザでページを見るときは、次の2段階で表示されています。

1. サーバーから **HTML** が届く
2. ブラウザが、HTMLに含まれる **JavaScript（プログラム）を実行** し、その結果でページの一部を書き足す

このアプリは通常、速くて相手サイトへの負担も小さい方法（requests + Beautiful Soup）でページを取得します。この方法では **1. のHTMLだけ** を受け取り、JavaScriptは実行しません。
そのため、**タグが 2. の段階で後から書き足されるサイト** では、受け取ったHTMLにタグがまだ存在せず、「タグが0件でした」というエラーになります。

注意が必要なのは、**開発者ツールの「Elements」タブは 2. の後の状態を表示している** ことです。つまり、開発者ツールではタグが見えてセレクタも合っているのに、アプリでは取れない、ということが起こります。

例：ページのソースでは、タグの欄が次のように **空っぽ** になっています。

```html
<ul id="tags" class="tags"></ul>
```

ブラウザで開くと、JavaScriptが後から中身（`<li><a href="/tag/test-all.html">test</a></li>`）を書き足します。

### 見分け方

**方法1：ページのソースを見る（いちばん確実）**

1. 記事ページで **`Ctrl` + `U`**（Macの Chrome は **`command` + `option` + `U`**）を押すか、右クリック →「ページのソースを表示」を選びます。これが **通常の方法でアプリが受け取るのと同じHTML** です。
2. `Ctrl` + `F`（Macは `command` + `F`）で、タグの文字（例：「Web開発」）を検索します。
3. 判定：
   - **見つかり、`<a ...>Web開発</a>` のようなHTMLの中にある** → 通常の方法で抽出できます。
   - **見つからない**（上の例のように、タグの欄が空）→ JavaScriptで後から表示されています。
   - **`<script>` の中（`{"tags":["Web開発", ...]}` のようなデータ）にだけある** → これもJavaScriptで表示されています。

**方法2：JavaScriptを止めて表示してみる**

1. 開発者ツールを開いた状態で **`Ctrl` + `Shift` + `P`**（Macは **`command` + `shift` + `P`**）を押します。
2. `javascript` と入力し、「**Disable JavaScript**（JavaScript を無効にする）」を選びます。
3. そのままページを再読み込みします。**タグが消えたら**、JavaScriptで表示されているサイトです。
4. 確認が終わったら、同じ手順で「Enable JavaScript」を選んで元に戻してください（開発者ツールを閉じても元に戻ります）。

**方法3：アプリのテスト機能**

設定画面の「タグ抽出のテスト」で、「JavaScriptを実行して試す」を **オフ** にしてタグが0件、**オン** にするとタグが取れる場合は、JavaScriptで表示されるサイトです。

### そのようなサイトの場合：「JavaScriptを実行して取得する」をオンにする

1. 設定画面の「タグ抽出のテスト」で、「**JavaScriptを実行して試す**」にチェックを入れてテストします。
2. タグが表示されたら、上の設定欄の「**JavaScriptを実行して取得する**」にチェックを入れて「設定を保存」します。
3. すでに「タグが0件でした」になっている記事は、一覧の「**エラーを再取得**」で取り直せます。

オンにすると、アプリは画面に表示されない「見えないブラウザ」（Playwright）でページを開きます。JavaScriptがタグを書き足すのを最大15秒待ってから、タグを取り出します。

- 1件の取得に数秒余分にかかります（タグが最後まで表示されないページでは、最大15秒待ちます）。まとめて登録しても、裏側で1件ずつ順番に処理するので、その間も画面は使えます。
- 速くするため、画像・動画・フォントは読み込みません。
- 使うブラウザは、起動ファイルが初回にダウンロードするもの（Chromium）です。ダウンロードに失敗していた場合は、PCに入っている **Microsoft Edge** か **Google Chrome** を代わりに使います。
- タグが普通に取れるサイトでは、オフのままの方が速く、相手サイトへの負担も小さくなります。

> ほかの方法として、[8-4](#8-4-meta-要素にタグが入っているサイト) の **meta 要素**（`meta[name="keywords"]` など）にタグが入っていれば、オフのままでも取得できます。ただし、meta要素もJavaScriptで後から設定するサイトがあります。

## 10. データとバックアップ

- すべてのデータ（記事・タグ・設定）は、アプリのフォルダにある **`tagclip.db`** という1つのファイルに保存されます。
- **CSVで保存**：一覧画面の「CSVで保存」、または設定画面の「CSVをダウンロード」で、全データをCSVファイルとしてダウンロードできます。Excelで開いても文字化けしません。複数のタグは ` | ` で区切って1つの欄に入ります。
- **完全なバックアップ**：アプリを停止した状態で、`tagclip.db` を別の場所（USBメモリやクラウドドライブなど）にコピーしておきます。戻すときは、そのファイルをアプリのフォルダに置き直すだけです。
- アプリを新しいバージョンに入れ替えるときも、`tagclip.db` を新しいフォルダにコピーすれば、データを引き継げます。

## 11. 困ったときは

| 症状 | 対処 |
|---|---|
| 起動ファイルを実行すると「Python が見つかりません」と出る | [3-1](#3-1-python-をインストールする) の手順でPythonをインストールし、PCを再起動してから再度試してください。Windowsでは「Add python.exe to PATH」のチェックが重要です |
| 「Address already in use」「アドレスは既に使用中」などと出て起動しない | すでにアプリが起動しています（別の黒い画面／ターミナルを確認）。または他のソフトが8000番を使っています。その場合は下の「ポート番号を変える」を参照 |
| スマホから開けない | [7-4](#7-4-それでもスマホから開けないとき) を確認してください |
| すべての記事が「タグが0件でした」になる | セレクタが合っていないか、JavaScriptで表示されるサイトです。[8章](#8-タグのcssセレクタの調べ方)・[9章](#9-javascriptでタグが表示されるサイトについて)を確認し、直したら一覧の「エラーを再取得」を押してください。JavaScriptで表示されるサイトなら「JavaScriptを実行して取得する」をオンにします |
| 「HTTPステータス 403」のエラーになる | サイト側が自動取得を拒否しています。このアプリでは取得できないので、手動でタグを入力してください |
| 「JavaScript実行用のブラウザを起動できませんでした」と出る | アプリを停止し、起動ファイルからもう一度起動してください（ブラウザ部品のダウンロードをやり直します）。それでも出る場合は、アプリのフォルダの `.venv` フォルダの中にある `browser_ready.txt` を削除してから起動し直すか、[手動で起動する方法](#手動で起動する方法うまくいかないとき仕組みを知りたいとき)の `playwright install chromium` の行を実行してください |
| 画面が古いまま | ブラウザの再読み込みボタンを押してください |

**ポート番号を変える**：8000番以外を使いたい場合は、環境変数 `TAGCLIP_PORT` を指定して起動します（例：PowerShell で `$env:TAGCLIP_PORT=8080; .venv\Scripts\python.exe app.py`、Macのターミナルで `TAGCLIP_PORT=8080 .venv/bin/python app.py`）。スマホのアドレスやファイアウォールの設定も、その番号に合わせてください。

**起動時にブラウザを自動で開かないようにする**：環境変数 `TAGCLIP_NO_BROWSER=1` を指定して起動します。

### ご注意

- このアプリは **自宅のWi-Fi内だけで使う** 前提のため、ログイン機能がありません。ルーターのポート開放などで **インターネットに公開しないでください**。
- 取得先サイトの利用規約を守り、個人の範囲で利用してください。取得間隔を短くしすぎないようにしましょう。
